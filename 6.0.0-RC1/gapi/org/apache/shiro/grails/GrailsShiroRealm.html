        • @groovy.transform.CompileStatic
          boolean[] isPermitted(org.apache.shiro.subject.PrincipalCollection principal, java.lang.String[] strings)

          Checks if the corresponding Subject implies the given permission strings and returns a boolean array indicating which permissions are implied.

          The Authorizer interface does not specify that it can throw an Authorization exception which is sensible for an boolean method. So if the PermissionResolver.resolvePermission() throws an InvalidPermissionStringException we return boolean[0]

          Parameters:
          principal - a PrincipalCollection
          strings - the permission Strings to use
          Returns:
          boolean array true if permitted
