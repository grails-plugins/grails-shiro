          Represents a default implementation of the GrailsRealmClass interface. This class is a wrapper around the specified class to provide meta-information and behavior specific to Realms. Extends org.grails.core.AbstractInjectableGrailsClass and implements the GrailsRealmClass interface to conform to the expected behaviour for a realm.
